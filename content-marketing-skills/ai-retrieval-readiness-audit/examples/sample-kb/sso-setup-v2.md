# Setting up single sign-on (SSO) for Acme Cloud

## Who can set up SSO

SSO is available on Acme Cloud Enterprise plans only. Workspace admins can configure it.

## Connect an identity provider to Acme Cloud

1. In Acme Cloud, open Settings, then Security.
2. Choose SAML or OIDC and paste your identity provider metadata URL.
3. Save, then test with a non-admin account before enforcing SSO.
