# Technical buyer personas

Reference for persona messaging. These are starting points; override them with anything the team knows from real buyers.

## Contents

- Developer / software engineer
- Platform, DevOps, or SRE lead
- Security leader (CISO, AppSec, cloud security)
- IT operations / infrastructure manager
- VP or director of engineering
- CIO / CTO
- CFO / procurement
- Public sector buyer (B2G)

---

## Developer / software engineer

- **Measured on:** shipping features, code quality, not getting paged
- **Distrusts:** marketing pages without docs links, "contact sales" for pricing, anything that adds a step to their workflow
- **Trusts:** docs, a free tier or open-source version, GitHub stars and issues activity, peers on Reddit/HN, code samples
- **Lands:** time saved per task, fewer context switches, works with tools they already use
- **Backfires:** "AI-powered," "for the enterprise," productivity percentages with no method

## Platform, DevOps, or SRE lead

- **Measured on:** reliability (SLOs, MTTR), developer self-service, cloud cost, toil reduction
- **Distrusts:** tools that create another dashboard to watch, agents that need root everywhere, lock-in
- **Trusts:** architecture diagrams, Terraform/Helm support, CNCF ecosystem fit, reference customers at similar scale
- **Lands:** fewer tickets, guardrails over gates, works with existing IaC and CI/CD
- **Backfires:** "rip and replace," "no-code" (to this audience it often reads as "not automatable")

## Security leader (CISO, AppSec, cloud security)

- **Measured on:** risk reduction, audit outcomes, incident response time, not slowing the business
- **Distrusts:** fear-based marketing, "100% protection," tools that flood them with alerts
- **Trusts:** third-party certifications, mapping to frameworks (NIST CSF, CIS, SOC 2, FedRAMP), analyst coverage, peer CISOs
- **Lands:** fewer false positives, prioritized findings, evidence for auditors, developer adoption without friction
- **Backfires:** breach-of-the-week scare tactics, "unhackable," vague "zero trust" claims

## IT operations / infrastructure manager

- **Measured on:** uptime, ticket volume, patch compliance, staying in budget
- **Distrusts:** tools that need a dedicated admin, surprise licensing changes
- **Trusts:** compatibility lists, migration guides, support SLAs, references at similar-sized orgs
- **Lands:** less manual work, consolidation of existing tools, predictable cost
- **Backfires:** developer-speak that assumes they write code daily

## VP or director of engineering

- **Measured on:** delivery velocity (DORA metrics), headcount efficiency, retention, quality
- **Distrusts:** tools their engineers will refuse to use, big-bang rollouts
- **Trusts:** what their senior engineers say, pilots, peer VPs
- **Lands:** team throughput, onboarding time, reducing toil that drives attrition
- **Backfires:** pitching around their engineers instead of with them

## CIO / CTO

- **Measured on:** strategic outcomes, risk, total cost, vendor consolidation
- **Distrusts:** point solutions that add sprawl, vendors who can't talk business outcomes
- **Trusts:** analyst reports, peer references, executive briefings, financial stability of the vendor
- **Lands:** consolidation, risk reduction, time to value, alignment with a stated initiative (cloud migration, AI adoption)
- **Backfires:** feature-level detail too early

## CFO / procurement

- **Measured on:** cost control, contract risk, ROI
- **Distrusts:** usage-based pricing they can't forecast, ROI calculators with heroic assumptions
- **Trusts:** clear pricing, cost comparisons against current spend, contract flexibility
- **Lands:** avoided headcount, retired tools, forecastable spend
- **Backfires:** "priceless," productivity claims that don't map to dollars

## Public sector buyer (B2G)

- **Measured on:** mission outcomes, compliance, spending authorized funds correctly
- **Distrusts:** vendors without the right authorizations, commercial messaging pasted onto government pages
- **Trusts:** FedRAMP / StateRAMP / IL levels, contract vehicles (GSA schedules, GWACs), past performance, system integrator partners
- **Lands:** mission language, compliance readiness, procurement path clarity
- **Backfires:** startup-style hype, ignoring the acquisition cycle
